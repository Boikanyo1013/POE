# QuickChat - POE Part 3

## What this app does
QuickChat lets a user send, store, disregard and search chat messages.

## Features
- Register and Login with username/password validation
- Send messages, check message ID, hash, and length
- Sent, Stored and Disregarded messages, search by ID/recipient, delete by hash, display longest message and full report

## How to run
1. Open project in NetBeans
2. Run Main.java
3. Use menu to send/store/search messages

## Tests
Run MessageTest.java to check Part 3 functions.
